# Gravitee AM Provider

The Gravitee AM provider allows you to manage [Gravitee Access Management](https://www.gravitee.io/platform/access-management) resources using Terraform.

## Compatibility

This provider targets the **Gravitee AM 4.12.1** Management API. Acceptance tests are run against Gravitee AM 4.12.1.

## Authentication

The provider authenticates to the Gravitee AM Management API using OAuth2 client credentials.

## Example Usage

```terraform
provider "graviteeam" {
  api_url       = "http://localhost:8093"
  client_id     = "admin"
  client_secret = "adminadmin"
}
```
